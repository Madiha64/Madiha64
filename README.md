##  Featured AI Projects & Research

###  Computer Vision & Structural Health Monitoring

**Deep Learning for Object Detection and Semantic Segmentation**

Research on deep learning pipelines for detecting and segmenting structural defects in concrete.

- Trained and evaluated DeepLabV3 and SegFormer models on structural-defect datasets.
- Developed a four-class U-Net segmentation pipeline with custom dataset loading and checkpoint management.
- Applied YOLOv8 for crack, spalling, and exposed-rebar detection.
- Evaluated model performance using class-wise IoU, F1-score, precision, and recall.
**Demo:** The manuscript is currently in preparation. Therefore, the source code and full implementation are not publicly available on GitHub. The repository will be made public after publication.

**Tech Stack:** PyTorch,SegFormer, DeepLabV3, U-Net, DDRNet, YOLOv8, yolov26,OpenCV.

### [Generative AI for Biomedical Imaging](https://github.com/Madiha64/Knee-Xray-Generative-AI)

Exploring synthetic knee X-ray generation to address medical-data scarcity and privacy challenges.

- Trained StyleGAN3 on 512 × 512 knee radiographs.
- Fine-tuned Stable Diffusion 1.5 using LoRA for domain-specific image generation.
- Experimented with pix2pix for image-to-image translation.
- Evaluated generated images using FID, SSIM, PSNR, and LPIPS.

**Tech Stack:** PyTorch, StyleGAN3, Stable Diffusion, LoRA, pix2pix.

---

###  [Trustworthy Medical RAG Assistant](https://github.com/Madiha64/ContextAware-Medical-RAG)

An evidence-grounded medical question-answering system designed to provide answers based on retrieved medical documents.

- Built a Retrieval-Augmented Generation pipeline using document chunking, semantic embeddings, and FAISS vector search.
- Integrated local LLM inference with Ollama and Llama 3.2.
- Evaluated answer faithfulness, relevancy, and context precision using RAGAS.
- Reported evaluation results of 96.7% faithfulness, 91.2% answer relevancy, and 80.1% context precision on a curated medical QA benchmark.

**Tech Stack:** Python, LangChain, FAISS, Ollama, Llama 3.2, RAGAS.

---

###  [LLM Fine-Tuning: SFT + DPO](https://github.com/Madiha64/Preference-Aligned-Medical-LLM)

Experimenting with preference alignment to improve small language models for medical question answering.

- Fine-tuned Llama-3.2-3B-Instruct using LoRA-based Supervised Fine-Tuning and Direct Preference Optimization.
- Designed pairwise, LLM-judged evaluations across accuracy, completeness, safety, clarity, and helpfulness.
- Observed a 90% preference rate for DPO-tuned outputs in head-to-head comparisons against SFT outputs in the evaluated experiment.

**Tech Stack:** Hugging Face Transformers, TRL, PEFT, LoRA, DPO.
